# Módulo de ensino Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cursos, inscrições, aulas (com professor e data), presença com chamada, linha do tempo do inscrito, presença pelo próprio aluno via QR Code e exportação CSV, com a presença modelada para escala.

**Architecture:** Quatro tabelas novas em Prisma/SQLite. `LessonAttendance` tem chave composta `(lessonId, memberId)` e grava só quem veio. Inscritos e presentes são listas paginadas na tela, então o formulário envia só o delta (`add`/`remove`), como `GroupMembersField` já faz. Telas `/cursos` e `/aulas` clonam o padrão de `/ministerios`. A página `/presenca/[lessonId]` é pública e fica fora de `(app)`.

**Tech Stack:** Next 16 (App Router, server actions), Prisma 7 + better-sqlite3, Mantine 9 (`Timeline`), zod, `qrcode.react` (dependência nova).

**Spec:** `docs/superpowers/specs/2026-11-27-ensino-design.md`

## Global Constraints

- **Sem testes automatizados** (decisão do usuário, é uma POC; salvo no claude-mem). Nada de harness, TDD ou `*.test.ts`. Isso substitui a seção 4 do `CLAUDE.md` para este módulo. Cada tarefa se verifica com `pnpm exec tsc --noEmit`, `pnpm lint` e o navegador (`preview_start`, login).
- Trabalhar direto na `main`, sem worktree; um commit por tarefa, sem push, `git add` com caminhos explícitos. A árvore está limpa (trabalho antigo commitado em `bebcafc`).
- `AGENTS.md`: este Next tem mudanças incompatíveis. Antes de escrever página, route handler ou server action de um tipo novo, ler o guia correspondente em `node_modules/next/dist/docs/01-app/` e copiar o padrão de `ministerios/`.
- Identificadores em inglês (`Course`, `Lesson`, `LessonAttendance`, `CourseEnrollment`); rotas, rótulos e mensagens em português (`/cursos`, `/aulas`, `/presenca`).
- Presença: `@@id([lessonId, memberId])`, `@@index([memberId])`, sem `id` e sem FK para a inscrição. Falta = ausência de linha.
- Cascade: curso → aulas, inscrições; aula → presenças; membro → inscrições e presenças. `Lesson.teacherId` é `Restrict`.
- Datas de aula são "só dia": `DateTime` guardado como meia-noite UTC, trafegado como string `YYYY-MM-DD`, exibido `DD/MM/AAAA` sem passar por fuso. "Hoje" é a data em `America/Sao_Paulo`.
- Páginas de 25 (`PAGE_SIZE`), cursor por chave ordenada, `take: PAGE_SIZE + 1` para saber `hasMore`.
- CPF é guardado só com dígitos; usar `onlyDigits` de `@/lib/cpf`.
- A página pública de presença não tem token nem limite de tentativas (POC, decisão do usuário).
